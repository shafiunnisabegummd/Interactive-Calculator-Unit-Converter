# Interactive Calculator & Unit Converter

## About the Project
A beginner-friendly Python command-line application
that performs arithmetic operations and converts units.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Kilometres to Miles
- Celsius to Fahrenheit
- Kilograms to Pounds
- Input validation
- Continuous menu system

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run:

python calculator.py
